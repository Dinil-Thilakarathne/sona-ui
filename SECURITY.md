# Security Policy

## Supported versions

Security fixes are applied to the latest version of Sona UI. Earlier releases
may not receive updates.

## Reporting a vulnerability

Please do not report security vulnerabilities through public GitHub issues.
Use GitHub's private vulnerability reporting channel for this repository and
include:

- A clear description of the issue and its impact.
- Steps to reproduce it, or a minimal proof of concept.
- The affected component, route, version, and environment.
- Any suggested remediation, if available.

We will acknowledge a report within 7 days and aim to provide a status update
or remediation plan within 30 days. Please give us reasonable time to resolve
the issue before sharing it publicly.
