Use Animated Dropdown when an action list needs keyboard-accessible menu behavior with a small, origin-aware entrance. Compose its trigger, content, items, and optional separators to match your product's actions.

## Install

<CodeBlockWrapper
  language="bash"
  filename="terminal"
  code={`npx shadcn@latest add @sona-ui/animated-dropdown`}
/>

## Basic usage

<CodeBlockWrapper
  language="tsx"
  filename="my-dropdown.tsx"
  code={`import {
  AnimatedDropdown,
  AnimatedDropdownContent,
  AnimatedDropdownItem,
  AnimatedDropdownSeparator,
  AnimatedDropdownTrigger,
  AnimatedDropdownTriggerIndicator,
} from "@/components/ui/animated-dropdown";
import { LogOut, Settings, User } from "lucide-react";

export function MyDropdown() {
  return (
    <AnimatedDropdown>
      <AnimatedDropdownTrigger>
        Account
        <AnimatedDropdownTriggerIndicator />
      </AnimatedDropdownTrigger>
      <AnimatedDropdownContent>
        <AnimatedDropdownItem icon={<User />}>Profile</AnimatedDropdownItem>
        <AnimatedDropdownItem icon={<Settings />}>Settings</AnimatedDropdownItem>
        <AnimatedDropdownSeparator />
        <AnimatedDropdownItem icon={<LogOut />} variant="danger">
          Log out
        </AnimatedDropdownItem>
      </AnimatedDropdownContent>
    </AnimatedDropdown>
  );
}`}
/>

## Examples

### Destructive action

Use the danger variant for an action that needs a destructive visual treatment. Add a separator when the destructive action belongs in its own group.

### Controlled state

Use controlled open state when another part of the interface needs to control the menu.

<CodeBlockWrapper
  language="tsx"
  filename="controlled-dropdown.tsx"
  code={`const [open, setOpen] = useState(false);

<AnimatedDropdown open={open} onOpenChange={setOpen}>
  <AnimatedDropdownTrigger>Menu</AnimatedDropdownTrigger>
  <AnimatedDropdownContent>
    <AnimatedDropdownItem onClick={() => setOpen(false)}>
      Close on click
    </AnimatedDropdownItem>
  </AnimatedDropdownContent>
</AnimatedDropdown>`}
/>

### Positioning

Use the side, alignment, and offset options to position the popup relative to its trigger.

<CodeBlockWrapper
  language="tsx"
  filename="positioned-dropdown.tsx"
  code={`// Opens to the right, aligned to the start of the trigger
<AnimatedDropdownContent side="right" align="start" sideOffset={8}>
  ...
</AnimatedDropdownContent>`}
/>

## Accessibility

The component uses Base UI menu semantics. It supports keyboard navigation, typeahead, focus management, and a modal menu by default. Keep item labels clear, and disable an item only when its action cannot be performed.

Use a non-modal menu only when people must continue interacting with surrounding content while it is open.

## Styling

Use the component class name options on the trigger, content, items, or separator to adapt the component to its context. The popup positions and scales from Base UI's transform origin, and reduced-motion preferences remove the entrance transition.
