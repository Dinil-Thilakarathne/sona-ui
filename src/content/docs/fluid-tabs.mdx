Use Fluid Tabs to switch between related views while keeping the selected surface visually connected. The active capsule or underline moves between items for pointer input and updates immediately for keyboard input.

## Install

<CodeBlockWrapper language="bash" filename="terminal" code={`npx shadcn@latest add @sona-ui/fluid-tabs`} />

## Basic usage

<CodeBlockWrapper language="tsx" filename="settings-tabs.tsx" code={`import FluidTabs from "@/components/ui/fluid-tabs/fluid-tabs";

const tabs = [
  { value: "general", title: "General" },
  { value: "security", title: "Security" },
];

export function SettingsTabs() {
  return <FluidTabs tabs={tabs} defaultValue="general" />;
}`} />

## Examples

Use the capsule variant for compact segmented navigation and the underline variant for editorial navigation. Controlled state works well when the selected view is reflected in the URL.

## Accessibility

Fluid Tabs uses Base UI tab semantics and keyboard navigation. Horizontal overflow keeps the active item available in narrow containers.

## Styling

The fluid-tabs token set controls the surface and indicator treatment. Reduced-motion preferences keep selection feedback without the travelling transition.
