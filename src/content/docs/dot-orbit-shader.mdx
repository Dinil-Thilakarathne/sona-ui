# Dot Orbit Shader

Animated multi-color dots, each orbiting around its cell center. Great for playful backgrounds, textures, and UI accents. Powered by [Paper Design Shaders](https://shaders.paper.design/).

## Features

- Up to 10 dot colors with automatic interpolation between them.
- Controls for dot size, size variation, and orbit spread.
- `stepsPerColor` multiplies the color count for richer gradients.
- Animatable with speed control — set to `0` for a static pattern.
