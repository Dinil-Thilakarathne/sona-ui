Use Dot Orbit Shader as a decorative background or texture. It renders colored dots that orbit inside a repeated grid and can run continuously or remain still.

## Install

<CodeBlockWrapper language="bash" filename="terminal" code={`npx shadcn@latest add @sona-ui/dot-orbit-shader`} />

## Basic usage

<CodeBlockWrapper
  language="tsx"
  filename="hero-background.tsx"
  code={`import DotOrbitShader from "@/components/ui/dot-orbit-shader/dot-orbit-shader";

export function HeroBackground() {
  return <DotOrbitShader className="absolute inset-0" speed={0.25} />;
}`}
/>

## Examples

Use a lower speed for ambient movement. Set speed to zero when the pattern should be static, and adjust colors, size, and spread to suit the background.

## Accessibility

Treat the shader as decorative and keep meaningful content outside it. Check text contrast against the final background and provide a reduced-motion alternative when needed.

## Styling

Use className to place the shader in a bounded layer. The component accepts color and motion options without requiring changes to its source.
