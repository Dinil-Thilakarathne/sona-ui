Use Ripple Button when an action benefits from a pointer-originating visual response. The ripple begins where the person points or presses, while the button keeps standard button behavior.

## Install

<CodeBlockWrapper language="bash" filename="terminal" code={`npx shadcn@latest add @sona-ui/ripple-button`} />

## Basic usage

<CodeBlockWrapper language="tsx" filename="ripple-button.tsx" code={`import RippleButton from "@/components/ui/ripple-button/ripple-button";

export function RippleAction() {
  return <RippleButton>Explore</RippleButton>;
}`} />

## Examples

Adjust the ripple scale, duration, and classes to fit the action. Use the text helper when the label needs its own treatment inside the button.

## Accessibility

Use a clear visible label or aria-label for icon-only actions. The ripple is supplementary feedback and does not replace focus or pressed states.

## Styling

The component forwards native button props, including disabled and event handlers. Reduced-motion preferences retain the interaction state without animated expansion.
