Use Fluid Tooltip for a related group of compact controls. One tooltip surface follows the active trigger, so labels remain oriented as someone scans a toolbar or navigation group.

## Install

<CodeBlockWrapper language="bash" filename="terminal" code={`npx shadcn@latest add @sona-ui/fluid-tooltip`} />

## Basic usage

<CodeBlockWrapper language="tsx" filename="toolbar-tooltips.tsx" code={`import FluidTooltip from "@/components/ui/fluid-tooltip/fluid-tooltip";

export function ToolbarTooltips() {
  return (
    <FluidTooltip.Group orientation="horizontal">
      <FluidTooltip.Root>
        <FluidTooltip.Trigger>Search</FluidTooltip.Trigger>
        <FluidTooltip.Content>Search this page</FluidTooltip.Content>
      </FluidTooltip.Root>
    </FluidTooltip.Group>
  );
}`} />

## Examples

Use a horizontal group for toolbars and a vertical group for stacked controls. The first pointer tooltip observes the configured delay, while adjacent tooltips open immediately.

## Accessibility

Fluid Tooltip uses Base UI tooltip semantics, collision-aware positioning, and accessible descriptions. Keyboard focus opens the relevant label immediately without directional travel.

## Styling

Use the group orientation and component class names to fit the control group. Reduced-motion preferences remove content travel while preserving the label.
