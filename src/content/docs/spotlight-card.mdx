Use Spotlight Card to add a subtle pointer-following highlight to a bounded card. It works with any child content and can be disabled when the surrounding context needs a static surface.

## Install

<CodeBlockWrapper language="bash" filename="terminal" code={`npx shadcn@latest add @sona-ui/spotlight-card`} />

## Basic usage

<CodeBlockWrapper language="tsx" filename="project-card.tsx" code={`import SpotlightCard from "@/components/ui/spotlight-card/spotlight-card";

export function ProjectCard() {
  return <SpotlightCard>Project details</SpotlightCard>;
}`} />

## Examples

Adjust the glow color and size to fit the card surface. Disable the effect in static or dense contexts where it would compete with the content.

## Accessibility

The spotlight is decorative. Ensure the card content has its own clear hierarchy and interaction states.

## Styling

Use className for the card surface and its children. The effect follows pointer movement without changing the layout.
