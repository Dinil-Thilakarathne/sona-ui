Use Animated Dialog for a modal task that needs an accessible dialog foundation and a short directional entrance. It provides the dialog structure, focus management, and close behavior while leaving the content and actions to your application.

## Install

<CodeBlockWrapper
  language="bash"
  filename="terminal"
  code={`npx shadcn@latest add @sona-ui/animated-dialog`}
/>

## Basic usage

<CodeBlockWrapper
  language="tsx"
  filename="confirm-dialog.tsx"
  code={`import {
  AnimatedDialog,
  AnimatedDialogClose,
  AnimatedDialogContent,
  AnimatedDialogDescription,
  AnimatedDialogTitle,
  AnimatedDialogTrigger,
} from "@/components/ui/animated-dialog/animated-dialog";

export function ConfirmDialog() {
  return (
    <AnimatedDialog>
      <AnimatedDialogTrigger>Delete project</AnimatedDialogTrigger>
      <AnimatedDialogContent from="bottom">
        <AnimatedDialogTitle>Delete this project?</AnimatedDialogTitle>
        <AnimatedDialogDescription>
          This action cannot be undone.
        </AnimatedDialogDescription>
        <div className="mt-6 flex justify-end gap-3">
          <AnimatedDialogClose>Cancel</AnimatedDialogClose>
          <AnimatedDialogClose className="bg-danger text-danger-foreground">
            Delete
          </AnimatedDialogClose>
        </div>
      </AnimatedDialogContent>
    </AnimatedDialog>
  );
}`}
/>

## Examples

### Direction

Set from and exitTo when the dialog should enter and leave in a particular direction. Use the center direction for a scale and fade treatment.

<CodeBlockWrapper
  language="tsx"
  filename="direction.tsx"
  code={`<AnimatedDialogContent from="left" exitTo="top">
  <AnimatedDialogTitle>Details</AnimatedDialogTitle>
</AnimatedDialogContent>`}
/>

### Controlled state

Use open and onOpenChange when another part of the interface needs to control the dialog state.

## Accessibility

The component uses Base UI dialog semantics, including focus management, Escape dismissal, and accessible labels. Include a title and description that clearly explain the task before asking someone to act.

## Styling

Style the content and action controls with class name options. Reduced-motion preferences replace directional movement with a simpler transition.
