# Animated Dialog

A composable, highly accessible dialog modal built on **Base UI** Dialog primitives and styled with **Framer Motion**. It supports directional slide transitions (animating from the top, bottom, left, right, or center).

## Features

- **Directional Entrance & Exit** — Configure modal transitions (`from` / `exitTo`) to slide from different vector origins.
- **Physics-Based Spring Easing** — Moves with natural momentum using spring calculations (`stiffness: 400, damping: 32`).
- **Standard Composable API** — Compose layouts with `AnimatedDialog`, `Trigger`, `Content`, `Title`, `Description`, and `Close`.
- **Portal & Accessibility** — Handles focus locking, scroll trapping, screen-readers, and rendering overlays cleanly via Base UI.
- **RTL & SSR Safe** — Hydrates styles without layout shifting.
- **Reduced Motion** — Seamlessly bypasses physical slide translations to fade in/out instantly.

## Code Examples

### Directional Slide

Choose how the content surfaces by setting the `from` and `exitTo` options.

<CodeBlockWrapper
  language="tsx"
  filename="directional-modal.tsx"
  code={`import {
  AnimatedDialog,
  AnimatedDialogContent,
  AnimatedDialogTrigger,
  AnimatedDialogTitle,
  AnimatedDialogDescription,
} from "@/components/ui/animated-dialog";

export function Modal() {
  return (
    <AnimatedDialog>
      <AnimatedDialogTrigger>Trigger</AnimatedDialogTrigger>
      {/* Slides in from the left, exits sliding up towards the top */}
      <AnimatedDialogContent from="left" exitTo="top">
        <AnimatedDialogTitle>Info</AnimatedDialogTitle>
        <AnimatedDialogDescription>
          Detailed descriptions here.
        </AnimatedDialogDescription>
      </AnimatedDialogContent>
    </AnimatedDialog>
  );
}`}
/>
