Use Button for an immediate action. It renders your content directly and adds a small press response without taking ownership of your action state or navigation.

## Install

<CodeBlockWrapper
  language="bash"
  filename="terminal"
  code={`npx shadcn@latest add @sona-ui/button`}
/>

## Basic usage

<CodeBlockWrapper
  language="tsx"
  filename="save-button.tsx"
  code={`import Button from "@/components/ui/button/button";

export function SaveButton() {
  return <Button>Save changes</Button>;
}`}
/>

## Examples

### Variants

Use the default variant for the primary action in a local context. Use outlined or secondary for supporting actions.

### Icon content

Pass icons and text as children. Keep the visible label clear enough to describe the action.

## Accessibility

Use a button label that describes the resulting action. When an icon is the only visible content, add an accessible name with aria-label.

## Styling

Use variant, size, and class name options to match the context. Reduced-motion preferences remove the press transform while preserving the interaction state.
