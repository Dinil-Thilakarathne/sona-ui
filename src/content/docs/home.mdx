# Sona UI

Sona UI is a source-owned component library for React. Each component is designed as a practical interaction pattern that you can install, inspect, and adapt inside your own project.

## What to expect

Sona UI focuses on accessible interaction, restrained motion, and components that remain easy to understand after installation. The library is intended to work with your existing tokens and application structure rather than replacing them.

## Start with a component

Open a component from the sidebar to review its purpose, preview, installation command, source, and API. Install only the components that fit the interaction you need.

## Work with the source

Components are installed as local source files through the shadcn CLI. That gives you ownership of the implementation and lets you adapt styling, layout, and behavior without depending on a black-box package.

## Contribute

Found an issue or have an idea for the library? [Open an issue on GitHub](https://github.com/Dinil-Thilakarathne/sona-ui/issues).
