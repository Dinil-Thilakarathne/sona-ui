Use Mesh Gradient Shader for a decorative background built from moving color spots, distortion, and vortex effects. It can provide subtle ambient motion or remain static behind content.

## Install

<CodeBlockWrapper language="bash" filename="terminal" code={`npx shadcn@latest add @sona-ui/mesh-gradient-shader`} />

## Basic usage

<CodeBlockWrapper language="tsx" filename="mesh-background.tsx" code={`import MeshGradientShader from "@/components/ui/mesh-gradient-shader/mesh-gradient-shader";

export function MeshBackground() {
  return <MeshGradientShader className="absolute inset-0" speed={0.2} />;
}`} />

## Examples

Adjust colors, distortion, swirl, and grain to fit the surface. Set speed to zero when the background should remain still.

## Accessibility

Treat the shader as decorative. Check text contrast against the final color field and provide a reduced-motion alternative for meaningful content.

## Styling

Use className to constrain the shader to its background layer. The color controls accept standard CSS color values.
