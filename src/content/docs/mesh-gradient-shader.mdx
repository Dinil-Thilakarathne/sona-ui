A flowing composition of animated color spots, shaped by organic distortion and vortex effects. Powered by [Paper Design Shaders](https://shaders.paper.design/).

## Features

- Up to 10 customizable color spots in any CSS color format.
- Independent distortion and swirl controls for organic or structured looks.
- Optional grain effects for added texture.
- Animatable with speed control — set to `0` for a static gradient.

## Examples

### Static

Set `speed={0}` to freeze the gradient — useful as a decorative background.
