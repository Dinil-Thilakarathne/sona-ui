Use Bubble Up Button for a small action that benefits from a visible hover response. The text remains readable while the background surface moves through the button.

## Install

<CodeBlockWrapper language="bash" filename="terminal" code={`npx shadcn@latest add @sona-ui/bubble-up-button`} />

<CodeBlockWrapper
  language="tsx"
  filename="bubble-button.tsx"
  code={`import BubbleUpButton from "@/components/ui/bubble-up-button/bubble-up-button";

## Examples

Pass button props for form behavior, disabled state, and event handlers. Use motionControls only when the default response does not fit the surrounding interaction.

## Accessibility

Use a visible label that states the action. The hover effect is supplemental, so the button remains usable with keyboard and touch input.

## Styling

Apply className to match the surrounding surface and text treatment. Reduced-motion preferences remove the animated response.
