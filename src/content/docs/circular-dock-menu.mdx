A circular trigger button that fans a set of items out in a radial arc on click, with staggered spring enter/exit animations and outside-click dismissal.

## Features

- Items animate out in a radial arc with configurable spring physics.
- Staggered entry and exit delays for a fluid cascade effect.
- Closes automatically on outside pointer interaction.
- Escape closes the menu and restores focus to the trigger.
- Supports controlled or uncontrolled open state and item selection callbacks.
- Fully customizable item list and spring parameters.
- Respects reduced-motion preferences.
