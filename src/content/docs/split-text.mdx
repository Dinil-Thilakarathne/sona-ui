Use Split Text to reveal a short heading or statement by characters, words, or lines. It uses GSAP splitting and waits for fonts before it measures line-based text.

## Install

<CodeBlockWrapper language="bash" filename="terminal" code={`npx shadcn@latest add @sona-ui/split-text`} />

## Basic usage

<CodeBlockWrapper language="tsx" filename="split-heading.tsx" code={`import SplitText from "@/components/ui/split-text/split-text";

export function SplitHeading() {
  return <SplitText variant="words"><h2>Build with care.</h2></SplitText>;
}`} />

## Examples

Use words or lines for longer text and characters for short Latin phrases. Set scrollTrigger when the reveal should begin as the text enters the viewport.

## Accessibility

Pass one element as the child so the component can split it safely. Reduced-motion preferences render the final text immediately.

## Styling

Use a block element with a defined width for line splitting. AutoSplit remeasures lines after a resize when the layout can change.
