# Accordion Component

The `Accordion` component is an accessible disclosure group built on Base UI. It supports controlled or uncontrolled state, single or multiple open items, and four existing visual variants.

## Features

- Base UI semantics and trigger/panel relationships.
- Controlled and uncontrolled open values.
- Single or multiple open items with `allowMultiple`.
- Interruptible height and opacity transitions without manual measurement.
- Reduced-motion handling for both panels and the plus/minus icon.
- Four variants: `default`, `outlined`, `splitted`, and `animated`.
