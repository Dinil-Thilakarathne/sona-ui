# Fan View

A trigger button that spreads labeled cards into a fanned arc layout on click, with staggered spring animations and outside-click collapse.

## Features

- Cards fan out with rotation and blur-to-clear spring transitions.
- Staggered entry and exit for a natural cascade feel.
- Collapses on outside pointer interaction or item click.
- Item widths are individually configurable.
- Supports controlled or uncontrolled state and item selection callbacks.
- Escape restores focus to the trigger, and reduced motion removes movement.
