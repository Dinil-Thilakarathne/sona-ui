Use Expanding Action when one compact control reveals a short set of related choices in the same place. The trigger and choices share one surface, so the interaction remains connected to its source.

## Install

<CodeBlockWrapper language="bash" filename="terminal" code={`npx shadcn@latest add @sona-ui/expanding-action`} />

## Basic usage

<CodeBlockWrapper language="tsx" filename="share-action.tsx" code={`import ExpandingAction from "@/components/ui/expanding-action/expanding-action";

export function ShareAction() {
  return (
    <ExpandingAction
      trigger="Share"
      items={[{ label: "Copy link" }, { label: "Send email" }]}
    />
  );
}`} />

## Examples

Use controlled open state when another control needs to manage the expanded choices. Keep labels short, and use disabled items only when an option cannot be performed.

## Accessibility

The trigger and choices use button semantics with keyboard focus states. Make each choice label specific enough to describe the resulting action.

## Styling

The component supports narrow containers and long labels through horizontal overflow. Reduced-motion preferences remove the expansion travel.
