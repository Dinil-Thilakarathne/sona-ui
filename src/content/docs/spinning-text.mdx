Use Spinning Text for a short decorative phrase that can orbit around an icon, mark, or focal point. Keep the text concise because the circular treatment is intended for recognition, not long reading.

## Install

<CodeBlockWrapper language="bash" filename="terminal" code={`npx shadcn@latest add @sona-ui/spinning-text`} />

## Basic usage

<CodeBlockWrapper language="tsx" filename="spinning-label.tsx" code={`import SpinningText from "@/components/ui/spinning-text/spinning-text";

export function SpinningLabel() {
  return <SpinningText>Explore Sona UI</SpinningText>;
}`} />

## Examples

Adjust duration, direction, radius, and text styling to fit the composition. Use reverse when the surrounding movement needs the opposite direction.

## Accessibility

The component includes a screen-reader-friendly text alternative. Do not use rotating text as the only place for essential information.

## Styling

Use className and the radius options to fit the text around a central element. Reduced-motion preferences should retain the text without continuous rotation.
