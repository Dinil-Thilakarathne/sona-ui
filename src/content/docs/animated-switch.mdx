Use Animated Switch for a binary setting that changes immediately. It uses Base UI switch behavior with a brief thumb stretch on press and a short state transition on release.

## Install

<CodeBlockWrapper
  language="bash"
  filename="terminal"
  code={`npx shadcn@latest add @sona-ui/animated-switch`}
/>

## Basic usage

<CodeBlockWrapper
  language="tsx"
  filename="notifications-switch.tsx"
  code={`import AnimatedSwitch from "@/components/ui/animated-switch/animated-switch";

export function NotificationsSwitch() {
  return <AnimatedSwitch defaultChecked aria-label="Enable notifications" />;
}`}
/>

## Examples

### Controlled state

Use checked and onCheckedChange when the switch reflects application state.

<CodeBlockWrapper
  language="tsx"
  filename="controlled-switch.tsx"
  code={`"use client";

import { useState } from "react";
import AnimatedSwitch from "@/components/ui/animated-switch/animated-switch";

export function ControlledSwitch() {
  const [checked, setChecked] = useState(false);

  return (
    <AnimatedSwitch
      checked={checked}
      onCheckedChange={setChecked}
      aria-label="Enable notifications"
    />
  );
}`}
/>

### Size and availability

Choose sm, md, or lg for the control size. Use disabled only when the setting cannot currently be changed.

## Accessibility

Provide an accessible name with a visible label or aria-label. The switch supports keyboard interaction and exposes its checked state to assistive technology.

## Styling

Use the size and class name options to fit the control into a settings row or compact toolbar. Reduced-motion preferences remove the animated state change.
