Use Hold To Delete Button for a destructive action that needs a deliberate confirmation gesture. The destructive fill reaches completion only when the control is held for the configured duration.

## Install

<CodeBlockWrapper language="bash" filename="terminal" code={`npx shadcn@latest add @sona-ui/hold-to-delete-button`} />

## Basic usage

<CodeBlockWrapper language="tsx" filename="delete-project.tsx" code={`import HoldToDeleteButton from "@/components/ui/hold-to-delete-button/hold-to-delete-button";

export function DeleteProject() {
  return <HoldToDeleteButton onDelete={() => console.log("Deleted")} />;
}`} />

## Examples

Adjust the hold duration to reflect the impact of the action. Release before completion to cancel, and use disabled when deletion is unavailable.

## Accessibility

The control supports pointer capture and keyboard activation. Make the destructive result clear in the visible label and surrounding explanation.

## Styling

Use the duration and class name options to match the context. Reduced-motion preferences retain the confirmation state without the animated fill.
