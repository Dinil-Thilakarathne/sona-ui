Use Magnetic Button for a playful pointer interaction around a focused call to action. The element shifts toward the pointer within the configured range, then returns to its resting position.

## Install

<CodeBlockWrapper language="bash" filename="terminal" code={`npx shadcn@latest add @sona-ui/magnetic-button`} />

## Basic usage

<CodeBlockWrapper language="tsx" filename="magnetic-action.tsx" code={`import Magnetic from "@/components/ui/magnetic-button/magnetic-button";

export function MagneticAction() {
  return (
    <Magnetic>
      <button type="button">Explore work</button>
    </Magnetic>
  );
}`} />

## Examples

Adjust the range and intensity to keep the response subtle. Use the parent interaction area when the surrounding surface should control the effect.

## Accessibility

Keep a real interactive element inside the wrapper and provide a clear action label. The pointer response is optional, so the content remains usable with keyboard input.

## Styling

Use className on the wrapper and style the child control for the visual treatment. Reduced-motion preferences keep the button at rest.
