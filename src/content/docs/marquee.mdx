Use Marquee for repeated content that can move through a bounded row, such as partner names or selected work. Keep the content understandable even when motion is disabled.

## Install

<CodeBlockWrapper language="bash" filename="terminal" code={`npx shadcn@latest add @sona-ui/marquee`} />

## Basic usage

<CodeBlockWrapper language="tsx" filename="logo-marquee.tsx" code={`import Marquee from "@/components/ui/marquee/marquee";

export function LogoMarquee() {
  return <Marquee>Selected clients</Marquee>;
}`} />

## Examples

Adjust speed and direction to suit the row. Pause or reduce movement when the content needs close reading.

## Accessibility

Do not make movement the only way to access information. Provide readable static content when reduced motion is preferred.

Use className to control the row width, spacing, and visual treatment of its children.
