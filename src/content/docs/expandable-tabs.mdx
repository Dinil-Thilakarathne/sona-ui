# Expandable Tabs Component

`ExpandableTabs` is an accessible horizontal tab selector that expands the active icon into a labeled pill. It uses Base UI for state and keyboard behavior, with input-aware Motion layout transitions.

## Features

- **Accessible foundation**: Base UI provides roving focus, disabled states, and arrow-key navigation.
- **Input-aware motion**: Pointer changes use spatial motion while keyboard changes remain immediate.
- **Controlled or uncontrolled**: Supports `value`, `defaultValue`, and `onValueChange`.
- **Customizable**: Override root, list, active-tab, and Motion configuration.
- **Reduced motion**: Removes spatial expansion while preserving clear active-state feedback.
