A continuous circular card marquee for visual browsing and ambient editorial motion. Cards orbit a shared elliptical path with depth-based scale, opacity, and stacking. It supports direction, speed, controlled pause, hover pause, and reduced motion.

## Behavior

The marquee renders one card per item and advances a single circular phase through Motion values. This keeps the loop continuous without cloning cards or updating React state on every frame. The orbit radius adapts to the card width and item count so neighboring cards preserve a readable gap.
