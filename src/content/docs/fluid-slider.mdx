Use Fluid Slider for a numeric value that benefits from direct adjustment. People can drag the indicator or select a position on the track, while the label and current value stay visible.

## Install

<CodeBlockWrapper language="bash" filename="terminal" code={`npx shadcn@latest add @sona-ui/fluid-slider`} />

## Basic usage

<CodeBlockWrapper language="tsx" filename="volume-slider.tsx" code={`import FluidSlider from "@/components/ui/fluid-slider/fluid-slider";

export function VolumeSlider() {
  return <FluidSlider label="Volume" defaultValue={50} />;
}`} />

## Examples

Use value and onValueChange for controlled state. Reference marks and formatted values help when the scale has meaningful thresholds.

## Accessibility

Fluid Slider uses Base UI range semantics, keyboard controls, and form integration. The semantic value stays within its constraints even when the visual edge response adds resistance.

## Styling

The fluid-slider token set lets you adapt surfaces, labels, and the boundary indicator to your theme. Reduced-motion and keyboard updates remain immediate.
