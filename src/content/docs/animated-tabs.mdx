Use Animated Tabs to switch between related views in the same part of a page. It provides keyboard navigation, disabled items, controlled state, and a shared hover indicator for pointer input.

## Install

<CodeBlockWrapper
  language="bash"
  filename="terminal"
  code={`npx shadcn@latest add @sona-ui/animated-tabs`}
/>

## Basic usage

<CodeBlockWrapper
  language="tsx"
  filename="account-tabs.tsx"
  code={`import AnimatedTabs from "@/components/ui/animated-tabs/animated-tabs";

const tabs = [
  { value: "profile", title: "Profile" },
  { value: "security", title: "Security" },
  { value: "billing", title: "Billing" },
];

export function AccountTabs() {
  return <AnimatedTabs tabs={tabs} defaultValue="profile" />;
}`}
/>

## Examples

### Controlled state

Use value and onValueChange when the selected view is also represented in page state or the URL.

### Disabled tabs

Disable a tab only when its destination is unavailable. Keep the label visible so people understand what will become available.

## Accessibility

Animated Tabs uses Base UI tab semantics and roving keyboard focus. The hover indicator is limited to pointer input, so keyboard navigation does not imply a hover state.

## Styling

Override the root, list, active item, and indicator classes to match the surrounding navigation. Reduced-motion preferences simplify the indicator transition.
