Use Image Trail for a decorative cursor effect inside a bounded editorial or portfolio area. Images appear only while a fine pointer moves, and the trail never intercepts links or buttons beneath it.

## Install

<CodeBlockWrapper language="bash" filename="terminal" code={`npx shadcn@latest add @sona-ui/image-trail`} />

## Basic usage

<CodeBlockWrapper language="tsx" filename="gallery-trail.tsx" code={`import ImageTrail from "@/components/ui/image-trail/image-trail";

export function GalleryTrail() {
  return <ImageTrail images={["/one.jpg", "/two.jpg"]}>Explore</ImageTrail>;
}`} />

## Examples

Choose scale, fade, blur, rise, or tilt for the image treatment. Use maxImages and ignoreSelector to keep the effect bounded around interactive content.

## Accessibility

The effect is decorative, ignores interactive elements, and runs only for a fine pointer. Reduced-motion preferences disable the trail.

## Styling

Use className to define the effect area and place meaningful content in the normal document flow.
