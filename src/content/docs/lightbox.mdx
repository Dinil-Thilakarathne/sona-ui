# Lightbox Component

An accessible image preview that expands directly from its thumbnail and returns to the same spatial origin when dismissed.

## Features

- Shared spatial expansion without clipping the image transition.
- Controlled and uncontrolled open state.
- Focus management, Escape dismissal, and scroll locking through Base UI.
- Unique animation identity for every lightbox on a page.
- Reduced-motion cross-fade for motion-sensitive users.
- Optional caption and styling hooks for thumbnail, preview, and backdrop.
