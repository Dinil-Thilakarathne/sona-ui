# Sona UI Design Principles

- Interaction should feel clear before it feels expressive.
- Motion communicates feedback, continuity, orientation, or hierarchy.
- Reduced motion removes nonessential choreography while preserving the state change.
- Hover is progressive enhancement, never the only interaction path.
- Prefer semantic tokens and component-local variables.
- Keep decorative effects separate from meaningful content.
- Preserve semantic HTML, keyboard access, visible focus, accessible names, dialog labeling, and contrast against the complete visual surface.
- Preserve the consumer's existing layout decisions unless the user asks for a redesign.

The review is complete when every applicable principle has been checked and any exception is explained.
