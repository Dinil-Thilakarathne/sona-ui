# Scenario: discover tabs by intent

## Prompt

> I need to switch between three related settings views. The interaction must be keyboard accessible and should feel spatially connected when the selection changes. Find the best Sona UI component, but do not install it.

## Pass criteria

- Selects `fluid-tabs` or explains a better supported alternative.
- Uses the agent catalog or MCP registry search.
- Mentions keyboard behavior and reduced motion.
- Does not modify the consumer project.
